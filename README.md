# mObywatel „Załatwione” – klikalny prototyp

Koncepcja na **mObywatel Challenge**. Aplikacja, w której państwo przychodzi do obywatela: sama zauważa ważny moment w życiu, przygotowuje wypełniony wniosek z danymi z rejestrów i prowadzi sprawę do końca. Użytkownik tylko sprawdza i podpisuje.

## Co można przeklikać

1. Urodziło się dziecko: 6 spraw w 4 instytucjach, 1 podpis
2. Przeprowadzka: meldunek, CEPiK i urząd skarbowy naraz
3. Pismo z urzędu skarbowego „po ludzku” i odpowiedź z fakturami
4. Udostępnij tylko „mam 18 lat”
5. Kto sprawdzał moje dane? Przycisk „To nie ja”
6. Zgubiony portfel: unieważnienie dowodu i zastrzeżenie PESEL
7. Nowy dowód, zanim wygaśnie
8. Kupno używanego auta: rejestracja bez kolejki
9. Pomoc bliskiej osoby: córka przygotowuje, mama zatwierdza
10. Tryb prosty dla seniorów (Pani Halina)
11. Asystent tekstowy i głosowy

## Technologia

Czysty HTML, CSS i JavaScript, bez bibliotek i bez serwera. Działa w każdej nowoczesnej przeglądarce, na telefonie i komputerze, bez logowania i bez kosztów. Mowa: Web Speech API przeglądarki. Asystent w prototypie działa na regułach (bez modelu AI). Docelowo: polski model Bielik lub PLLuM.

## Uruchomienie lokalnie

Otwórz `index.html` w przeglądarce albo uruchom dowolny serwer statyczny, np. `python3 -m http.server`.

Niezależny prototyp koncepcyjny. To nie jest oficjalna aplikacja mObywatel ani usługa administracji publicznej. Wszystkie osoby, dokumenty i dane są fikcyjne. Nic nie jest nigdzie wysyłane.
